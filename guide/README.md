# Portal Interactivo de Aprendizaje Progresivo IPvN7

Este directorio alberga la experiencia de divulgación, inducción interactiva y convencimiento empírico de **IPvN7 Network OS**, gobernada por el **Sub-Rol U (Evangelizador & Maestro Interactivo de Adopción Soberana)** según DEC-136.

---

## 📂 Estructura de la Carpeta

- `index.html`: Portal web interactivo con 5 capas de descubrimiento cognitivo.
- `style.css`: Sistema de diseño biomórfico cyberpunk glassmorphism a 60 FPS (Vanilla CSS, <400L).
- `app.js`: Motor reactivo de simulaciones físicas (ataque cuántico, failover Kleinberg, orbe Zen y ECG, <400L).
- `GUIA_SOBERANA_HUMANA.md`: Manifiesto y guía conceptual en prosa cotidiana para todo público.

---

## 🚀 Cómo Usar este Portal

### 1. En Navegador Local Offline (Doble Clic)
Puedes abrir directamente `index.html` en Google Chrome, Microsoft Edge, Firefox, Safari o Brave con doble clic sin necesidad de conexión a Internet ni servidor web.

### 2. Integrado en el Daemon WebUI de IPvN7
Cuando el nodo `ipvn7.exe` está ejecutándose (puerto 7070 por defecto), la guía se sirve automáticamente en la ruta canónica:
```text
http://127.0.0.1:7070/guide/
```
o mediante el botón interactivo **"🧭 Guía Interactiva"** en la interfaz principal.
